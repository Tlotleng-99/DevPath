The proper cs name

A unit test checks that one small unit of code (a function, a class) works correctly. Tests catch bugs before users do.

  • assert result == expected — check the output matches.
  • pytest — popular Python testing framework.
  • unittest — Python's built-in test module.
def test_add():
    assert add(2, 3) == 5
    assert add(-1, 1) == 0
    assert add(0, 0) == 0

# Run: pytest test_math.py
# All tests passed!

Where they live: professional software development, CI/CD pipelines, open-source projects — anywhere quality matters.
