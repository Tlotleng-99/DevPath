The proper cs name

An array (or list) stores multiple values in order. Each value has an index — its position, starting from 0.

  • items[0] — first item (index 0).
  • items.append(x) — add to the end.
  • items.pop() — remove and return the last item.
  • len(items) — how many items in the array.
shelves = ["Coke", "Bread", "Wipes"]

print(shelves[0])      # "Coke"
print(len(shelves))    # 3
shelves.append("Fanta")
print(shelves[-1])     # "Fanta" (last item)

Where they live: shopping carts, leaderboards, playlists, search results — anywhere you need an ordered collection.

The story, slowly 🧠

1

Numbered shelves

Each item at the spaza has a shelf number. Shelf 0 is first, shelf 1 is second, and so on.

2

One name, many items

Instead of item1, item2, item3, you have one array: shelves[0], shelves[1].

3

Add to the end

New stock arrives? Append it to the end of the array. The array grows automatically.

4

Access by position

Need the third item? shelves[2]. Arrays give you instant access by index — no searching needed.
