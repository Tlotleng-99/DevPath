🍲 The Pap Recipe

A function is a recipe: ingredients go in, steps run, pap comes out. Write it once, use it for 1000 Sundays.

Try it yourself live

The recipe is the function, the number of people is the input, and the bowls of pap are the return value. Press a button and watch the function run.

def make_pap(people):
    # 1 cup water + 1/2 cup mealie meal per person
# call the function with an argument

The proper cs name

A function packages instructions under a name so you can reuse them. It takes inputs (parameters), runs its body, and can send back a return value.

  • def make_pap(people) — define it once.
  • make_pap(4) — call it with an argument.
  • return ... — hand the result back.
def make_pap(people):
    water = people * 1.0      # cups
    mealie = people * 0.5     # cups
    return f"{people} bowls of pap"

print(make_pap(4))  # -> "4 bowls of pap"

Where they live: every library you'll ever import is just a collection functions. Once a function exists, you never rewrite its steps.

The story, slowly 🧠

1

Write it once

Gogo doesn't re-discover magwinya every Sunday — she just follows her method. A function is the same method, stored once under a name.

2

Inputs go in

How many people are eating? That's the argument. The function takes it as a parameter and adapts: 1 person, 4 people, 20 people — same recipe.

3

Steps run

Measure mealie, boil water, stir, let it rest. The body of the function runs top to bottom on every call.

4

Output comes out

The function returns its result — bowls of pap — so the rest of your program can use it. Input → process → output.
