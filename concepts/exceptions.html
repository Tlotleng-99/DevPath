When things go wrong, have a plan B

🔌 Load Shedding Survival

Exceptions handle errors gracefully. When the power goes out, you need a backup plan — that's exception handling.

The proper cs name

An exception is an error that occurs during execution. try/except catches errors so your program doesn't crash.

  • try: — attempt the risky operation.
  • except Error: — catch the error and handle it.
  • finally: — always runs, success or failure.
try:
    plug_in()
except SparkError:
    use_battery()   # Plan B!
except SurgeError:
    surge_protector.activate()
finally:
    print("Power management complete")

Where they live: file operations, network requests, user input validation — anywhere things can go wrong.

The story, slowly 🧠

1

Try the risky thing

Plug in the appliance. It might work... or it might spark. You don't know yet.

2

Catch the error

It sparked! The except block catches the error before it crashes your program.

3

Handle it gracefully

Switch to battery power. The error is handled — your program keeps running.

4

Clean up

The finally block always runs — log the incident, close connections, whatever needs doing.
