The proper cs name

A data structure is a way of organising data so it can be accessed and modified efficiently.

  • Stack — LIFO: Last In, First Out (like a stack of plates).
  • Queue — FIFO: First In, First Out (like a taxi rank).
  • List — ordered collection, accessible by index.
  • Dictionary — key-value pairs, fast lookup.
stack = []
stack.append("plate1")  # push
stack.append("plate2")
stack.pop()             # returns "plate2" (LIFO)

queue = []
queue.append("person1")  # enqueue
queue.append("person2")
queue.pop(0)             # returns "person1" (FIFO)

Where they live: every program uses data structures — undo stacks, task queues, database indexes, cache systems.

The story, slowly 🧠

1

Stack = fatcake stack

Last fatcake placed is the first one taken. LIFO — like a stack of plates or a pile of vetkoek.

2

Queue = taxi rank

First person in line is the first to get a taxi. FIFO — fair and orderly, like a proper kasi queue.

3

Choose the right one

Need to reverse order? Use a stack. Need to preserve order? Use a queue. The problem decides.

4

Real-world impact

Browser back button = stack. Print job queue = queue. Understanding these helps you pick the right tool.
