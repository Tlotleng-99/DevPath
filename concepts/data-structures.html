Same items, different order

🧱 The Kasi Line-Up

A stack gives you the newest item first. A queue gives you the oldest item first. Same data, two very different rules.

Try it yourself live

Add and remove items in both structures. Watch the fatcake pile and the taxi rank reveal what LIFO and FIFO actually mean.

🚕 Taxi queue FIFO

New passengers join the back. Call from the front — first in, first out.

The proper cs name

A data structure is a way of organising data so the program can use it efficiently. A stack follows LIFO — Last In, First Out. A queue follows FIFO — First In, First Out.

  • push(item) / pop() — add and remove at the stack's top.
  • enqueue(item) / dequeue() — add at the back and remove from the queue's front.
  • Choose the structure based on the order your problem needs.
# Stack — LIFO: newest first
fatcake_stack = ["Chips", "Beef kota"]
fatcake_stack.append("Vetkoek")
fatcake_stack.pop()       # -> "Vetkoek"

# Queue — FIFO: oldest first
taxi_queue = ["Thabo", "Zinhle"]
taxi_queue.append("Pieter")
taxi_queue.pop(0)         # -> "Thabo"

The story, slowly 🧠

1

One pile, one line

The fatcakes and taxi passengers are just items. The data structure decides which item the program is allowed to reach next.

2

Stack means newest first

Put something on a stack and it becomes the top item. Remove from a stack and that newest item leaves first. That is LIFO.

3

Queue means oldest first

Join the back of a queue and wait your turn. Remove from the front and the person who arrived first gets served. That is FIFO.

4

The rule follows the job

Undo needs the latest action, so it uses a stack. A taxi rank must be fair, so it uses a queue. Choosing the right structure makes the code simpler.
