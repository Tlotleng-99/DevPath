Named boxes that hold values

🏪 The Spaza Stash

A variable is a labelled box: give it a name, put a value inside, and read it back whenever you need it.

Try it yourself live

The spaza shelf holds stock items. Each item has a name and a price — that's a variable. Update it when prices change.

# click a button to update a variable

The proper cs name

A variable is a named container that stores a value. The name stays the same, but the value inside can change — that's the whole point.

  • price = 15 — create a variable called price, store 15.
  • price = price + 2 — read the old value, add 2, store it back.
  • print(price) — outputs 17.
stock = "Coke"
price = 15
price = price + 2   # price is now 17
print(price)        # 17

Where they live: every app, game, and website uses variables to remember things — your score, your name, what's in your cart.

The story, slowly 🧠

1

Label the box

Every item at the spaza has a name — Coke, bread, wipes. In code, that name is the variable name: price, stock.

2

Put something inside

The price of Coke is R15. You store that value: price = 15. The box now holds 15.

3

Read it back

When a customer asks "how much?", you read the variable: print(price). You don't need to remember — the variable does.

4

Update when things change

Supplier prices go up? Just change the value: price = price + 2. The name stays, the value updates. Sharp.
