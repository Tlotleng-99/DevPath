Russian dolls all the way down

🪆 The Matryoshka Method

Recursion is when a function calls itself. Like Russian dolls — open one, find another inside, repeat until you reach the smallest one.

The proper cs name

Recursion is when a function calls itself to solve a smaller version of the same problem. It needs a base case to stop.

  • Base case — when to stop (the smallest doll).
  • Recursive case — call yourself with a smaller input.
  • Call stack — each call waits for the next to finish.
def count_dolls(n):
    if n == 0:           # base case
        return "smallest doll!"
    return count_dolls(n - 1)  # recursive call

print(count_dolls(3))
# Opens doll 3 → doll 2 → doll 1 → smallest!

Where they live: tree traversal, factorial calculation, Fibonacci sequence, file system navigation, divide-and-conquer algorithms.

The story, slowly 🧠

1

Open the outer doll

You have a big Russian doll. Inside is a smaller one. That's the recursive call — same problem, smaller size.

2

Keep opening

Each doll contains a smaller one. The function calls itself again and again, each time with a smaller doll.

3

Reach the base case

Finally you reach the smallest doll — it doesn't open. That's the base case. No more recursive calls.

4

Unwind the stack

Now you close each doll in reverse order. The call stack unwinds, returning values back up the chain.
