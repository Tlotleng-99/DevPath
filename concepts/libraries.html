🌶️ Don't Grind It, Import It

Libraries are pre-written code you can use directly. Why grind every spice when you can buy a ready mix?

Try it yourself live

Import different libraries and see what they can do. No grinding required.

Click a button to import and use a library...
# import statement will appear here

The proper cs name

A library (or module/package) is a collection of pre-written code you can import and use in your own programs.

  • import math — gives you sqrt, pi, sin, cos.
  • import random — random numbers, choices, shuffles.
  • from datetime import date — work with dates and times.
import math
import random

print(math.sqrt(144))        # 12.0
print(math.pi)               # 3.14159...
print(random.randint(1, 6))  # dice roll

Where they live: every Python program uses libraries — from web frameworks (Django) to data science (pandas) to game dev (pygame).

The story, slowly 🧠

1

Don't reinvent the wheel

Need to calculate a square root? Someone already wrote that. Import it and move on.

2

Import the library

import math loads the library into your program. Now all its functions are available.

3

Use its functions

Call math.sqrt(144) — the library does the hard work, you get the answer.

4

Build on top

Combine multiple libraries to build complex things quickly. That's the sharp way.
