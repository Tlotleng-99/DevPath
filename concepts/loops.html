Repeat until done

🍳 Fry Until the Pot is Empty

Loops repeat the same action multiple times without you having to copy-paste code. The kitchen runs on loops.

Try it yourself live

Click to fry fatcakes. The loop keeps frying until the count reaches zero — no copy-paste needed.

# while loop will appear here

The proper cs name

A loop repeats a block of code. while loops until a condition is false; for loops a set number of times.

  • while pot_not_empty: — keep frying while there's batter.
  • for i in range(10): — fry exactly 10 fatcakes.
  • break — stop the loop early if needed.
batter = 10

while batter > 0:
    fry_fatcake()
    batter -= 1   # one less to fry

# Or with a for loop:
for i in range(10):
    fry_fatcake()

Where they live: processing lists, reading files line by line, game loops, retrying failed operations.

The story, slowly 🧠

1

Set the condition

How much batter is left? That's the loop's condition — it checks before every iteration.

2

Do the work

Fry one fatcake. That's the loop body — the action that repeats.

3

Update the counter

Batter goes down by one. Without this, the loop runs forever!

4

Check again

Still batter left? Go back to step 2. No batter? Exit the loop. Sharp.
