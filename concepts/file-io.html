Save data, read it back later

📒 The Spaza Notebook

RAM forgets when you switch off. The spaza notebook remembers — writing to a file is how programs remember across restarts.

Try it yourself live

The notebook is a file. Jot each sale (write), total the takings (read), start a fresh page (clear). The data lives after the page closes.

# open('notebook.txt', 'w') to start fresh

The proper cs name

File I/O is reading from and writing to files so data outlives the program. Three modes you will use daily:

  • 'r' — read (open the book to check).
  • 'w' — write (new page, wipes old page).
  • 'a' — append (add a line without erasing).
# write / append
with open('takings.txt', 'a') as f:
    f.write('R40 · maize meal\n')

# read back
with open('takings.txt', 'r') as f:
    data = f.read()
print(data.splitlines())

Where they live: config files, saved games, logs, databases underneath, analysis pipelines. Any app that remembers you when it restarts.

The story, slowly 🧠

1

RAM forgets

The moment the program closes, its variables vanish. Only what's written to a file — the notebook — survives power-off.

2

Write = jot it down

'Record a sale' appends one line to the file. Old lines stay — the notebook grows through the day.

3

Read = tally it up

At close of day you open the book and read each line. Reading a file pulls the saved data back into your program.

4

Persist or lose it

Files are the cheapest memory there is. Every real app leans on them: 'remember my username', 'keep my saved game', 'log everything'.
