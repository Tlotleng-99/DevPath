The proper cs name

File I/O (Input/Output) reads data from files and writes data to files. Files persist after your program stops.

  • open("file.txt", "w") — open for writing.
  • open("file.txt", "r") — open for reading.
  • file.write(data) — write data to file.
  • file.read() — read data from file.
with open("sales.txt", "w") as f:
    f.write("Coke R15\n")
    f.write("Bread R12\n")

with open("sales.txt", "r") as f:
    print(f.read())  # prints all sales

Where they live: saving user data, loading configurations, logging, exporting reports — anywhere data needs to persist.

The story, slowly 🧠

1

Open the notebook

Start a new page — open the file in write mode. The notebook is ready.

2

Jot down the sale

Sold a Coke for R15? Write it down. file.write("Coke R15").

3

Close the notebook

Done writing? Close the file. Data is saved safely on disk.

4

Read it back later

End of day? Open the file in read mode and tally up. The data is still there.
