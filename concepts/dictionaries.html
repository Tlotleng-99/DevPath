📖 The Spaza Price List

A dictionary maps keys to values. Like a price list — look up "Coke" and get R15. No numbers needed, just names.

The proper cs name

A dictionary (or hash map) stores key-value pairs. Look up a key, get its value — instant access by name.

  • prices["Coke"] — get value for key "Coke".
  • prices["Fanta"] = 14 — add or update an entry.
  • "Coke" in prices — check if key exists.
  • prices.keys() — get all keys.
prices = {
    "Coke": 15,
    "Bread": 12,
    "Wipes": 22
}

print(prices["Coke"])       # 15
prices["Fanta"] = 14        # add new item
print("Coke" in prices)     # True

Where they live: user profiles, configuration settings, database records, JSON APIs — anywhere you need fast lookup by name.

The story, slowly 🧠

1

Name → price mapping

The spaza price list maps each item name to its price. "Coke" → R15. That's a key-value pair.

2

Instant lookup

Customer asks "how much for bread?" You look up "Bread" in the dictionary — R12. No searching through a list.

3

Add new items

New stock arrives? Add it: prices["Fanta"] = 14. The dictionary grows dynamically.

4

Update prices

Supplier prices change? Update the value: prices["Coke"] = 17. The key stays, the value changes.
