🔍 CV Skena (Regex)

Regular expressions find patterns in text. Hunting for emails in a pile of CVs? Regex finds them in one sweep.

The proper cs name

A regular expression (regex) is a pattern that describes a set of strings. Use it to search, match, and extract text.

  • \d+ — one or more digits.
  • [a-z]+ — one or more lowercase letters.
  • ^start — matches beginning of string.
  • end$ — matches end of string.
import re

text = "Contact: thabo@email.com or 0821234567"
emails = re.findall(r"[\w.]+@[\w.]+\.\w+", text)
phones = re.findall(r"0\d{9}", text)

print(emails)  # ['thabo@email.com']
print(phones)  # ['0821234567']

Where they live: search engines, form validation, log parsing, data extraction — anywhere you need to find patterns in text.

The story, slowly 🧠

1

Describe the pattern

What are you looking for? An email has @ and a dot. A phone starts with 0. Describe it.

2

Write the regex

Translate the description into regex syntax. [\w.]+@[\w.]+\.\w+ matches emails.

3

Search the text

Run the regex against your text. It finds all matches in one sweep — no manual searching.

4

Extract the matches

Get all matches as a list. Now you have clean data ready to use.
