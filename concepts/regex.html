Pattern-based treasure hunt

🔍 CV Skena (Regex)

Instead of reading every line, regex hunts text by pattern: find the numbers, find the emails, find the prices. Skena ke skena.

Try it yourself live

This is a scrap of a CV. Pick a pattern and regex scans the whole text in one pass, highlighting every match and counting it.

# pick a pattern to search for

The proper cs name

A regular expression (regex) is a pattern that searches text. One pattern can validate or extract in a way manual code can't touch.

  • \d — any digit.
  • [0-9] — digits 0 to 9.
  • + — 'one or more of the thing before'.
  • ^…$ — anchor start and end.
import re

# does this look like a SA cell number?
pattern = r"^0[678]\d{8}$"
if re.match(pattern, "0825551234"):
    print("Yep, valid Mzansi number! ✓")

Where they live: form validation, log filtering, search-and-replace, scraping, and checking that an email looks like an email.

The story, slowly 🧠

1

Don't read it — scan it

Reading 200 CVs line by line is sleep therapy. Regex scans the whole pile for one pattern in a blink, like a barcode reader.

2

The pattern is the language

0[678]\d{8} says: starts with 0, then 6/7/8, then 8 more digits. Every metacharacter is a rule your pattern must obey.

3

Match, not guess

Regex doesn't eyeball — it matches the rule exactly. '0825551234' passes the rule; '5551234' doesn't, because the rule is strict.

4

Validate and extract

Two superpowers: validate (is the number real?) and extract (pull every price out of this document). One pattern, both prizes.
