# 🚀 DevPath

DevPath is an e-learning platform that helps students learn coding through clear study materials, coding exercises, and peer-to-peer learning. It was inspired by our experience at WeThinkCode_, where we saw how helpful learning from each other can be — but also how hard it can be to find clear, organised study materials.

## ✨ Features

- User registration and login
- Coding learning materials and exercises
- Course/topic sections
- Progress tracking
- Peer-to-peer learning and support

## 🛠️ Technologies

Java, HTML, CSS, JavaScript, MySQL, Git & GitHub, JUnit, Maven

## 📖 How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Configure the MySQL database.
4. Install Maven dependencies.
5. Run the application.
